# Punyam Charitable Trust Website - Context Document

## Technical Stack & Requirements

### Core Frontend Technologies
- **HTML5**
  - Semantic markup for better accessibility
  - Modern HTML elements for structured content
  - Responsive meta tags

- **CSS3 with Bootstrap 5**
  - Mobile-first responsive design
  - Custom theming and components
  - Flexbox and Grid layouts
  - Modern animations and transitions

- **JavaScript**
  - Vanilla JS or Alpine.js for lightweight interactivity
  - DOM manipulation for dynamic content
  - Event handling for user interactions

### UI Components & Libraries
- **Navigation System**
  - Custom responsive navigation bar
  - Dropdown menus for Bala Bhavan sub-sections
  - Mobile hamburger menu

- **Maps Integration**
  - Google Maps API implementation
  - Custom markers for trust location
  - Interactive map controls

- **Icons & Visual Elements**
  - FontAwesome/Heroicons integration
  - Custom icon set for services
  - Vector graphics for better scaling

- **Animations**
  - AOS (Animate On Scroll) library
  - Smooth section transitions
  - Performance-optimized animations

### SEO & Performance
- **Search Engine Optimization**
  - Meta tags implementation
  - OpenGraph tags for social sharing
  - Structured data markup
  - XML sitemap

- **Analytics & Monitoring**
  - Google Analytics integration
  - User behavior tracking
  - Performance monitoring

- **Performance Optimization**
  - Lighthouse testing implementation
  - Image optimization
  - Lazy loading for images
  - Minification of assets

## Content Structure

### Front Page
The front page should provide a compelling introduction to the trust through:

1. **Mission & Values**
   - Trust's core mission statement
   - Organizational values
   - Impact statistics

2. **Core Services**
   - **Medical Help**
     - Financial assistance programs
     - Medical treatment support
     - Healthcare partnerships

   - **Rehabilitation**
     - Societal reintegration programs
     - Support systems
     - Success stories

   - **Educational Support**
     - Scholarship programs
     - Educational resources
     - Tuition assistance details

   - **Punnyam Bala Bhavanam**
     - Orphanage overview
     - Care programs
     - Support services
